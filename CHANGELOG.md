# Changelog

## 0.1.4 - 2026-03-31

- added dedicated loading and composition sections for decoding, object-position presets, and editorial archetype controls
- exposed richer image composition presets for hero, editorial, gallery, poster, duotone, and vignette-style layouts
- threaded the new decoding attribute through live preview and React export so the preview/export path stays aligned
- reorganized motion and filter controls into more button-like section cards and cleaned the image accessibility checklist copy

## 0.1.3 - 2026-03-31

- standardized image preset metadata into explicit family, archetype, variant, and size fields
- upgraded preset filtering so the image browser can slice the generated catalog by structured preset metadata instead of tags only

## 0.1.2 - 2026-03-31

- expanded the preset system from starter packs into larger generated button-style preset catalogs
- aligned the preset browser and preview reset flow more closely with the button-component product model
- preserved clean lint, typecheck, and production build verification after the canon sync

## 0.1.1 - 2026-03-31

- added a searchable preset catalog with full-state preset apply flow
- aligned the image studio more closely with the button-style UI Foundry editing model
- preserved clean lint, typecheck, and production build verification after the preset rollout

## 0.1.0 - 2026-03-30

- stabilized the standalone image app so build, lint, and typecheck pass
- synced shared layout and control primitives to the UI Foundry standard
- preserved a self-contained image playground and export workflow
